# AGENTS.md

## 対象範囲

このファイルのルールは、`/docs/DB/ER` 配下のER図に適用する。

## 記載するカラム

- エンティティには、原則としてPKとFKのみを記載する。
- リレーションの把握に必要な場合を除き、一般カラムは記載しない。
- PKとFKは、Mermaidのカラム定義上でそれぞれ `PK`、`FK` と明記する。

## リレーションのコメント

- 各リレーションには、その関係と多重度が分かる日本語のコメントを付ける。
- コメントは、リレーションの左側に記載したエンティティを主語として記述する。
- 同じエンティティ間に役割の異なるリレーションが複数ある場合は、作成者・更新者などの役割が区別できるコメントをそれぞれ記載する。
- コメントの表現とエンティティ名の表記は、同じER図内で統一する。

## リレーション階層

- リレーションは、上位・親となるエンティティから下位・子となるエンティティの順で記載する。
- 親子関係を逆向きに記載せず、左側を親、右側を子に統一する。
- 同じ階層または同じ親を持つリレーションは近くにまとめ、全体の階層を追える順序にする。
- 中間テーブルがある場合は、親エンティティから中間テーブルへの関係として記載し、階層を飛び越えた直接の関係を追加しない。

## 変更範囲

- 作業時は、依頼で指定されたファイル以外を変更しない。
- 指定外の誤りや改善点を見つけても、その場で修正せず、/docs/todo配下の適切なフォルダにMarkdown形式でAGENTS.mdの指示に従い記録する。
