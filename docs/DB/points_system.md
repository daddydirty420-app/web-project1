# ポイント系ルール

## ポイント系テーブル

- points_history: ポイント獲得・利用履歴
- point_lots: ポイント有効期限、使用歴（先入れ先出し法）
- point_reason_option: ポイント獲得・利用に対する理由マスターテーブル

## PointsHistory（ポイント獲得・利用履歴）

### SQL

```
CREATE TABLE IF NOT EXISTS public.points_history
(
    id integer NOT NULL GENERATED BY DEFAULT AS IDENTITY ( INCREMENT 1 START 1 MINVALUE 1 MAXVALUE 2147483647 CACHE 1 ),
    points integer,
    user_id integer NOT NULL,
    "createdAt" timestamp with time zone DEFAULT now(),
    "updatedAt" timestamp with time zone DEFAULT now(),
    reason_id integer,
    CONSTRAINT points_history_pkey PRIMARY KEY (id),
    CONSTRAINT fk_points_history_reason_id FOREIGN KEY (reason_id)
        REFERENCES public.point_reason_option (id) MATCH SIMPLE
        ON UPDATE CASCADE
        ON DELETE RESTRICT,
    CONSTRAINT points_history_user_id_fkey FOREIGN KEY (user_id)
        REFERENCES public."user" (id) MATCH SIMPLE
        ON UPDATE CASCADE
        ON DELETE NO ACTION
)
```

### カラム詳細

- points: integer ポイント獲得・利用に対する数値
    - ポイント獲得：80
    - ポイント利用：-250
- reason_id: integer point_reason_optionとのリレーションカラム
