# 売上金ルール

## 売上金系テーブル

- uriagekin_history: 売上金獲得・利用履歴
- uriagekin_lots: 売上金有効期限、使用歴（先入れ先出し法）

- User.uriagekin（現在残高）

## UriagekinHistory（売上金獲得・利用履歴）

### SQL

```
CREATE TABLE IF NOT EXISTS public.uriagekin_history
(
    id integer NOT NULL GENERATED BY DEFAULT AS IDENTITY ( INCREMENT 1 START 1 MINVALUE 1 MAXVALUE 2147483647 CACHE 1 ),
    uriagekin integer,
    user_id integer NOT NULL,
    "createdAt" timestamp with time zone DEFAULT now(),
    "updatedAt" timestamp with time zone DEFAULT now(),
    CONSTRAINT uriagekin_history_pkey PRIMARY KEY (id),
    CONSTRAINT uriagekin_history_user_id_fkey FOREIGN KEY (user_id)
        REFERENCES public."user" (id) MATCH SIMPLE
        ON UPDATE CASCADE
        ON DELETE NO ACTION
)
```

### カラム詳細

- uriagekin: integer 売上金獲得・利用に対する数値
    - 売上金獲得：8000
    - 売上金利用：-25000

### 更新

- INSERTのみ

## UriagekinLots

### SQL

```
CREATE TABLE IF NOT EXISTS public.uriagekin_lots
(
    id serial NOT NULL,
    uriagekin integer NOT NULL,
    user_id integer NOT NULL,
    used_uriagekin integer NOT NULL DEFAULT 0,
    expires_at timestamp with time zone NOT NULL,
    "createdAt" timestamp with time zone NOT NULL DEFAULT CURRENT_TIMESTAMP,
    "updatedAt" timestamp with time zone NOT NULL DEFAULT CURRENT_TIMESTAMP,
    CONSTRAINT uriagekin_lots_pkey PRIMARY KEY (id),
    CONSTRAINT uriagekin_lots_user_id_fkey FOREIGN KEY (user_id)
        REFERENCES public."user" (id) MATCH SIMPLE
        ON UPDATE CASCADE
        ON DELETE CASCADE
)
```

### カラム詳細

- uriagekin: integer 売上金獲得額
- used_uriagekin: integer 売上金利用に対する当該獲得売上金の使用
    - 先入れ先出し法で売上金を使用
        - 例：10/18 1000円獲得、10/20 500円獲得、10/21 1300円利用した場合
        - 10/18 used_uriagekin: 1000、10/20 used_uriagekin: 300（残り200円使用可能）
- expires_at: timestamptz 有効期限

### 更新

- 獲得時 INSERT
- 利用時 UPDATE（used_uriagekin更新）
