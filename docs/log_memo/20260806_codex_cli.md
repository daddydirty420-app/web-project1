# Codex CLI 導入メモ

「Codex が CLI にもあるらしい！」と思い、まずは `codex` コマンドを実行してみた。

……が、そもそもインストールされていなかった😅

案内に従って `sudo ...` のコマンドでインストールし、認証まで完了。

さっそく起動してみると、利用できる最新モデルが **GPT-5.4**、しかもデフォルトは **gpt-5.3-codex**。

「まあ 5.3-codex で試してみるか」と思ったら、

> このモデルはサポートされていません

とのこと😅

仕方なく GPT-5.4 を選択して使い始めたものの、今度は `node` や `npm` など、基本的なコマンドすら認識されない。

「GUI 版と同じ問題じゃないか……😅」

そこで ChatGPT に相談したところ、

```bash
npm install -g @openai/codex
```

でインストールし直したほうが良いとのこと。

言われた通りにインストールし直して、もう一度認証。

すると今度は **GPT-5.6 シリーズ** が選べるようになっていた✨

今回は標準モデルの **GPT-5.6-terra** を選択。

試してみると、今度は `node` や `npm` も問題なく認識され、CLI 環境が正常に動作。

ESLint の設定も整えたことで、Codex がローカル環境で実際にコードを編集・実行・レビューまで行える状態になった。

最初はインストール方法の違いでかなりハマったけど、最終的には期待していた開発環境が整って一安心🔥
