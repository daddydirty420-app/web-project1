## POST /transfer/points — 売上金ポイント変換

### リクエスト

- body:
    - value
    - limit

### ビジネスロジック

- bodyバリデーションチェック
- ユーザー情報取得
- 売上金履歴マップ化
- 売上金履歴古い順に削除
- 帳簿データ作成
- ポイント履歴データ作成
- ポイント変換ログ作成
- ユーザー情報更新
- お知らせ作成（非同期）
