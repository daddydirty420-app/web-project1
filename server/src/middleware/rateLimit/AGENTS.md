## このディレクトリについて

各ルーティングに適用するレート制限ミドルウェアを、機能単位で配置するディレクトリです。

## 実装ルール

-   `express-rate-limit` を使用し、ルートの処理内容に対応する `○○RateLimit` という名前で export する。
-   `windowMs` と `limit` は、処理の負荷や悪用リスクを考慮し、同種の既存実装に合わせて設定する。
-   `standardHeaders: true`、`legacyHeaders: false` を設定する。
-   認証済みユーザー単位で制限する処理では、`AuthUser` と `keyGenerator` を使用し、既存実装と同じ形式でユーザー ID をキーにする。
-   ユーザー ID を参照するレート制限は、ルーティングで認証ミドルウェアより後に適用する。
-   同じ機能のレート制限は同一ファイルにまとめ、新規作成時は既存ファイルの命名と構成に合わせる。
